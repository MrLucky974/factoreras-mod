# FactorEras

## About
A mod for Voxel Eras aiming to add more machines and stuff.

## Content
### Assembling Machine
This machine automate the production of most items that are only craftable manually (Basic Workbench & Anvil recipes). Needs *Clockwork Energy* to be able to run.

Right-click to open the menu and select a recipe to start production.

### Bricks
You can make bricks from grout by mixing gravel and sand in the mortar & pestle. Bricks can be used to construct a brick block which serves as a new decoration block for your factories and builds.

### Clockwork Sieve
Extract new useful materials from gravel and sand by putting it into the clockwork sieve!

### Sap & Rubber Bar + Tree Tap
Place a Tree Tap next to a tree to collect sap over time. Sap can be turned into rubber by smelting it into a furnace.

You can construct a rubber block to make your own crazy rooms. Rats not included.

### Gunpowder
Made from mixing coal and sulfur dust into the mortar & pestle. Used in recipes to make stuff explode.

### Bomb
Crafted with gunpowder, this block adds a bit of chaos to the game. Not useful in anyway but it's funny.
